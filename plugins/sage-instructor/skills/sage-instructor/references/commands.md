# Sage Codex routes

The original command files are retained in `source-commands/` as an upstream
audit record only; do not execute their Claude-specific paths. In Codex, use
these explicit routes with the same state transitions and safeguards:

`sage start` · `sage next` · `sage lesson` · `sage challenge` · `sage checkpoint` ·
`sage progress` · `sage drill` · `sage review` · `sage hint` · `sage explain` ·
`sage stuck` · `sage recap` · `sage status` · `sage help` · `sage reset` ·
`sage phase` · `sage tracks` · `sage switch` · `sage new-track` · `sage exercise`.

Accept the published slash-like aliases (`/sage-start`, `/sage-next`, and so
on) as equivalent invocation wording. Keep all per-route confirmation gates,
progress updates, toolchain-vs-learner diagnosis, and source-recording rules
from the retained command artifacts.
