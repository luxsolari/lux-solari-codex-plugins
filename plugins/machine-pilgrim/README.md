# Machine Pilgrim

A Codex-native migration of Lux Solari's Machine Pilgrim GPT. It creates finished standalone artworks, illustrated-book pages, and cinematic sequences grounded in the canon and visual language of *Descent into the Machine*.

The package includes the original master prompt, recovered GPT configuration, the original source text, compact operational instructions, and all 18 original PNG knowledge references.

```sh
codex plugin add machine-pilgrim@lux-solari-codex
```
