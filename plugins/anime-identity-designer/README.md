# Anime Identity Designer

A Codex-native migration of Lux Solari's Anime Identity Designer GPT. It creates finished anime portraits, branding boards, expression sheets, costume studies, and character bibles while preserving the real subject's recognizable identity.

The package includes the original master prompt, recovered GPT configuration, compact operational instructions, and all 13 original PNG knowledge references.

```sh
codex plugin add anime-identity-designer@lux-solari-codex
```
